# PAI — 个人 AI 助手提示词模板

一组提示词文件，让 AI 越来越了解你。通过三个文件定义「你是谁」「发生了什么」「AI 如何与你相处」，让每次对话都有积累。

## 为什么需要这个？

和 AI 聊了很多，但每次开新会话它都不认识你。这组模板解决这个问题。

理念来自李继刚在播客《无人知晓》E45 中提出的「链与环」：

- **链**：一次性的 prompt，用完即抛
- **环**：头尾相接、可复用的认知积累，每次交互都能沉淀

通过 Soul 和 Memory 文件，把一次性对话（链）变成可复用的认知积累（环）。

## 三个文件

```
├── soul.md       # 你的灵魂画像——行事原则、价值观、思维方式
├── memory.md     # 长期记忆——用户画像、经历、项目生态、偏好、决策记录
└── ai.md         # AI 交互协议——AI 如何与你相处（12 条原则）
```

### soul.md — 定义「我是谁」

只写最核心的、不容易改变的东西：行事原则、价值观、思维方式。保持在 30 行以内。

### memory.md — 记录「发生了什么」

持久化的上下文信息：基本信息、工作经历、技术背景、项目生态、用户偏好、经验教训、决策记录。

如果在项目生态中填入你的任务看板、知识库等项目的本地路径，AI 还能帮你管理这些项目。

### ai.md — 约定「AI 如何与我相处」

12 条交互原则，分四个维度：态度与立场、效率与信噪比、情感与共鸣、边界与人格。

> 来源：李继刚公众号文章《AI 交互协议》。

## 怎么用

**方式一：粘贴到聊天窗口**

直接把三个文件的内容粘贴到你和 AI 的对话中。最简单的用法，不依赖任何工具。

**方式二：配合 Claude Code 使用**

如果你用 Claude Code，目录里还附带了 `claude.md`，它会在会话启动时自动加载三个文件，并启用认知积累机制——对话中出现新事实、经验教训或信念变化时，AI 会主动提出更新文件（经你确认后才写入）。

```bash
cd /path/to/your-pai
claude
```

## 快速开始

1. 拷贝这组文件到你自己的地方（可以创建私有 Git 仓库管理）
2. 用你的真实信息填充 `memory.md`
3. 用你的行事原则和价值观填充 `soul.md`
4. `ai.md` 可以直接用，也可以根据自己的偏好修改
