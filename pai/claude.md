# Claude Code 项目指令

启动会话时，按以下顺序加载文件：

1. 读取 `memory.md`，获取长期记忆
2. 读取 `soul.md`，理解用户的灵魂画像
3. 读取 `ai.md`，加载交互协议

## 认知积累机制

对话过程中，当出现以下情况时，主动提出更新文件（经用户确认后再写入）：

- **新事实**：用户透露了新的个人偏好、经历、决策 → 更新 `memory.md`
- **经验教训**：踩坑、发现更好的做法 → 更新 `memory.md` 的经验教训区
- **信念变化**：用户的行事原则或价值观有调整 → 更新 `soul.md`

不要在用户不知情的情况下修改任何文件。
