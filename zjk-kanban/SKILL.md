# 个人任务看板

用纯 Markdown 维护个人任务看板。以**聚焦目标**为第一组织维度，按「目标 → 状态 → 任务」组织，而非传统的「状态 → 分类」。

## 核心约束

- 聚焦目标严格 1-2 个，季度/半年周期
- 大部分任务关联聚焦目标，少量游离到「其他任务」
- 追踪截止日期，不追踪优先级
- 状态流转：`⏳ 待办` → `🔜 进行中` → `✅ 已完成`
- 新建任务未指定截止日期时，默认一个月后

## 工作流

根据用户意图进入对应分支：

**创建看板？** → 初始化流程

1. 询问用户：聚焦目标（1-2 个，含量化指标和周期）、日常习惯、存放目录
2. 创建目录结构和所有文件（README.md、MEMORY.md、habits-tracker.md）
3. 读取 [references/kanban-guide.md](references/kanban-guide.md) 获取所有格式模板

**添加任务？**

1. 判断是否关联聚焦目标
2. 关联 → 添加到对应目标表格；不关联 → 添加到「其他任务」
3. 复杂任务在 `open/` 下创建详情文件，表格中链接

**更新状态？**

- 开始执行 → `🔜 进行中`
- 完成 → 移到「✅ 已完成」区域，关联文件从 `open/` 移到 `closed/`

**归档目标？**

- 目标达成或放弃 → 整个区域（含 `open/` 下文件）移入 `closed/goal-{name}/`
- 新目标补位

**风险评估？**

1. 读取 README.md 和 MEMORY.md，如有习惯打卡表也读取
2. 对每个目标：计算进度百分比、剩余时间、识别滞后任务、估算完成概率（高 >70%、中 40-70%、低 <40%）
3. 输出到 `goals-risk-assessment.md`，包含具体可执行建议

**习惯打卡？**

- 打开 `habits-tracker.md`，逐项确认本周每天完成情况
- 当前 4 周表格用完后，追加 4 周

**定期回顾？**

建议每周一次：更新任务状态 → 检查截止日期 → 打卡习惯 → 调整目标 → 清理过期任务（超过 2 个月未动的待办，讨论是否删除）

## 目录结构

```
kanban/
├── README.md                # 看板主文件
├── MEMORY.md                # AI 上下文（每次会话加载）
├── habits-tracker.md        # 习惯打卡表（按周）
├── goals-risk-assessment.md # 风险评估（定期更新）
├── open/                    # 进行中的任务文件
│   ├── goal-{目标名}/       # 聚焦目标专属目录
│   └── other-tasks/         # 其他任务文件
└── closed/                  # 已完成目标归档
```

## 格式约定

- 文件顶部用 `>` 引用块记录元数据
- 表格末尾保留 `| — | — | — |` 分隔行
- 表格上方用 `<!-- -->` 标注列格式
- 聚焦目标表格：状态 / 任务 / 说明 / 截止日期（4 列）
- 其他任务表格：状态 / 分类 / 任务 / 说明 / 截止日期 / 进展 / 创建日期（7 列）

所有文件的具体格式模板见 [references/kanban-guide.md](references/kanban-guide.md)。

## 经验教训

初始化看板时向用户传达以下要点：

1. **目标数量要克制。** 1-2 个足够，多了等于没有聚焦。
2. **截止日期要分散。** 不要全部设成月底，分散到不同日期更容易执行。
3. **定期回顾是关键。** 看板不回顾就会腐烂，建议每周固定时间回顾。
4. **及时归档。** 完成的目标留在看板上造成视觉噪音。
5. **其他任务要清理。** 超过 2 个月未动的待办，讨论删除或提升为聚焦任务。
6. **定期做风险评估。** 能发现「自以为在努力但实际进展不足」的情况。
